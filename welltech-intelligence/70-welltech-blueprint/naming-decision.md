# Naming Decision — Mesura (Mesura Health)

> **Canonical build version now lives in the Mesura build repo: `github.com/r0yb0ymana/mesura`** (Mesura-named throughout, with a ranked Plan B fallback). This copy is retained for research context.

**Working name locked:** the new company (the WhatsApp-native medical weight-loss / metabolic service, a WellTech Health subsidiary piloting through Medimind KL) will operate as **Mesura**, brand **Mesura Health**, tagline **"Metabolic health, measured."**

**Status: provisional working name — adopted, pending trademark + SSM clearance.** This document is the decision record. Until clearance completes, the execution docs continue to use "NewCo" as the generic term (see the propagation action below).

Last updated: July 2026.

## Decision

| Field | Value |
|---|---|
| Company / working name | **Mesura** |
| Consumer brand | **Mesura Health** |
| Tagline | **Metabolic health, measured.** |
| Status | Provisional — pending MyIPO trademark + SSM name clearance |

## Why Mesura

- **Meaning is on-thesis.** *Mesura* is Latin / Catalan / Portuguese for *measure* — so the name literally carries the "measured" half of the positioning, and the tagline reads almost as a definition: *Mesura — metabolic health, measured.*
- **Warm, human sound.** Three syllables, soft *-a* ending (me-SOO-ra) — it kept everything that resonated about the earlier front-runner "Metera," and pronounces cleanly across Bahasa Malaysia, English and Mandarin.
- **Clear in the health class.** The clash pass (below) found **no health/medical "Mesura"** — the only namesakes are in unrelated fields — so the medical trademark class looks open. This is the specific test that Metera, Vytal and Numera all failed.
- **Broad & gender-neutral.** It signals metabolic health generally, not weight specifically and not a gender — so it stretches from the v1 weight-loss wedge into metabolic and longevity without a rename.

## Alternatives considered & why rejected

| Name | Verdict | Reason |
|---|---|---|
| **Metera** | Rejected | Loved the meaning, but a US biotech (Metera Pharmaceuticals) and a Taiwan medtech (metera.com.tw) sit in the health/pharma space → trademark risk; the "meter-" root is crowded; bare `.com` gone. |
| **Vytal** | Rejected | Direct in-category collisions — **Vytal Health** and **Vytal Living** already run functional-medicine / metabolic / weight telehealth. |
| **Numera** | Rejected | **Numera** is an existing telehealth / health-monitoring brand ("measured wellness"), 20+ years, and holds `numera.com`. Direct clash. |
| **Metry** | Passed over | Clear in health (only namesake is a Swedish energy-data SaaS), but the "-metry" root is generic/descriptive and `metry.com` is held elsewhere. |
| **Metriva** | Rejected | An existing Metriva in the medical-product space + they hold `metriva.com`. |
| **Calibro / Calibra** | Passed over | No health clash, but crowded across other fields (staffing, calibration software) and hard to own; Calibra also carries the dead Facebook-crypto association. |

## Clash findings (the evidence)

- **No health/medical "Mesura" found.** Web search of "Mesura + health/clinic/medical/wellness" surfaced no Mesura brand.
- The only "Mesura" namesakes are **industrial gas meters/regulators** ([mesura.com](https://www.mesura.com/), Cavagna Group, France) and an **architecture & design studio** ([mesura.eu](https://www.mesura.eu/), Barcelona) — both unrelated trademark classes.
- **`mesura.com` is owned** by the gas-meter company — so the bare `.com` is not available; use a variant/lockup (below).

## Caveats

- This decision was made from desk research. **A definitive registrar (WHOIS) and MyIPO/SSM check could not be run in this environment** — the findings are directional and must be confirmed by the actions below before any spend or public use.
- *Mesura* means "measure/moderation" in Romance languages, so it is mildly **descriptive** in those markets (a minor trademark-strength consideration there); in Malaysia / English / Chinese it reads as a distinctive coined brand, and the meaning is a feature.

## Action list to finalise (Phase 0)

1. **MyIPO trademark search** — Class 44 (medical services) + Class 5 (pharma) for "Mesura" / "Mesura Health"; file if clear.
2. **SSM company-name reservation** for the subsidiary.
3. **Register domains** (in priority order): `mesura.my` / `mesura.com.my` (Malaysia-first launch), `mesura.health`, `mesurahealth.com`, then `getmesura.com` / `trymesura.com`. (Optionally a later low-ball enquiry to the gas company for `mesura.com`.)
4. **Secure social handles** (`@mesurahealth` and variants) across Instagram, TikTok, Facebook, LinkedIn.
5. **Once cleared:** propagate "Mesura" across the repository (replace the generic "NewCo" in [../PHASE-0-HANDOFF.md](../PHASE-0-HANDOFF.md), [build-roadmap.md](build-roadmap.md) and the other blueprint docs).
